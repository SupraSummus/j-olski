# Korpus usterek: zdania z usterką, którą sprawdzacz ma zgłosić, wraz z poprawką.
#
# Plik stoi poza `harness/`, bo program jest kasowalny, a sąd o zdaniu nie —
# ten sam powód, który podaje nagłówek `próba/wybory.txt`.
#
# Ten plik jest kolejką roboty toru gramatycznego: mówi, jakich zgłoszeń autor
# potrzebuje, a `python3 -m harness.usterki` mówi, które z nich olski już wydaje.
# Po co kolejka stoi tu, a nie w banku drzew, mówi
# docs/roadmap.md#kolejkę-ustawia-korpus-usterek-a-nie-kolejka-blokerów
#
# Wpis stoi tu wtedy, gdy jego zgłoszenie ma świadka: odczytanie zdania albo
# odczytanie zdania naprawionego. Usterka, o której orzeka znaczenie słowa,
# a nie kształt zdania, wpisem nie jest, bo takiego wpisu nie zamyka żadna robota:
# docs/subset.md#wpis-korpusu-usterek-nazywa-kształt-zdania-a-nie-znaczenie-słowa
#
# `zdanie` niesie usterkę, którą czytelnik by poprawił.
# `usterka` mówi jednym zdaniem, co jest nie tak.
# `zgłoszenie` nazywa zgłoszenie, które ma paść: nazwą, którą je nazywa olski,
# kiedy takie zgłoszenie już jest, a nową nazwą, kiedy go nie ma.
# Chwyt rejestru stoi tu nazwą swojej reguły, a nie nazwą flagi, bo pod jedną
# flagą stoi kilka reguł i nazwa wspólna nie mówi, która z nich padła.
# Nowa nazwa jest wpisem kolejki, a nie deklaracją: zgłoszenie dopisane do
# olskiego bierze tę nazwę albo wpis bierze jego.
# `poprawka` niesie to samo zdanie bez usterki i zgłoszenie ma nad nim milczeć;
# zgłoszenie padające nad obojgiem nie widzi usterki, tylko coś obok niej.
# `kontekst` niesie zdania stojące przed zdaniem, kiedy usterki nie widać bez nich,
# i stoi tak samo przed poprawką.
# `odczytanie` nazywa role, których zgłoszenie potrzebuje, po jednej na wiersz,
# w postaci `rola: wypełnienie`, i nazywa je tak, jak nazywa je werdykt;
# rola, której gramatyka nie zna, jest wpisem kolejki tak samo jak nowa nazwa
# zgłoszenia. Wpis, którego ról nie obsadza naraz żadne odczytanie, wychodzi
# `źle czytane`, a wpis bez tego pola zostaje w ciszy.
# Wpis czysty ma `zgłoszenie: żadne`, a poprawki ani odczytania nie ma:
# jest zdaniem bez usterki,
# a szumem jest nad nim każde zgłoszenie poza wierszem o odczytaniach.
# Wiersz ten szumem nie jest, bo wieloznaczność jest odpowiedzią, a nie
# znaleziskiem, i poprawiać nad nią nie ma czego:
# docs/subset.md#wieloznaczność-jest-odpowiedzią-a-nie-znaleziskiem
#
# Zdania są pisane ręką pod ten plik, a nie brane z korpusu, bo usterka ma tu
# być jedna i nazwana; rozkład rejestru mierzy baza sądów, nie ten plik.

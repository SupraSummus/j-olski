# Ciągi wokół łącznika `to`, których olski nie ma wyprowadzać
#
# Plik stoi poza `harness/`, bo program jest kasowalny, a sąd o zdaniu nie —
# ten sam powód, który podaje nagłówek `próba/wybory.txt`
#
# Czyta go sonda różnicowa jako plik prozy: `nad_prozą` w `harness/ruch.py`
# segmentuje tekst i przepuszcza każde zdanie przez każdy wariant,
# a przejście `odrzucone → przyjęte` jest tu ceną, a nie zakupem,
# i na tym polega cała różnica między tym plikiem a prozą repozytorium
#
# Materiał ten jest potrzebny dlatego, że Składnica zawiera wyłącznie zdania
# poprawne, więc pomiar nad nią nie ukarze wariantu za przyjęcie ciągu,
# którego wyprowadzić nie wolno, i nie naprawia tego dogęszczenie banku drzew
#
# Żaden wiersz komentarza nie kończy się kropką i jest to warunek działania
# tego pliku, a nie ozdoba: napis bez znaku zamykającego nie jest zdaniem
# i do mianownika nie wchodzi, a wiersz zakończony kropką wchodzi do niego
# jako zdanie poprawne i psuje liczbę, o którą ten plik jest pytany
#
# Zestaw obejmuje jeden łącznik, a nie całą gramatykę;
# zestaw negatywny dla całej gramatyki jest osobnym przedsięwzięciem

# Przypadek inny niż mianownik po którejś stronie łącznika

Kotem to jest zwierzę.
Kot to zwierzęciem.
Kot to zwierzęcia.
